# Wexresprise Store

Отдельное Android-приложение — полка файлов сообщества. Не сайт и не WebView.

## Что умеет

- Две вкладки: **Все** и **Wexresprise Projects**.
- **Все** — все опубликованные файлы: APK, видео, аудио, картинки, документы.
- **Wexresprise Projects** — файлы, у которых включён флажок проекта или в названии есть «Wexresprise».
- **Опубликовать** — выбрать любой файл на телефоне, добавить название и описание, загрузить.
- Карточка файла: иконка, название, описание, размер, дата и кнопка **Скачать**.
- У APK показывается настоящая иконка приложения: она вынимается при публикации и лежит
  рядом с файлом в Supabase (`icon_path`). Если иконки нет — рисуется Material-глиф.
- Установка APK прямо из магазина: файл скачивается во временную папку приложения и
  открывается системный установщик. Если Android ещё не разрешил установку из этого
  источника, приложение объясняет это и открывает нужный экран настроек, а после
  возврата продолжает установку само.

## Оформление

Кнопка-палитра на главном экране открывает **Оформление**:

- тема: системная, светлая, тёмная;
- акцент: системный Material You (Android 12+) или один из семи цветов;
- фон: «аврора» (анимация), градиент, сплошной;
- карточки: стекло, сплошные, контур;
- радиус углов и размер текста — ползунками;
- плотность списка: свободная или компактная;
- иконка на рабочем столе: шесть вариантов Material-сумки (зелёная, синяя,
  фиолетовая, оранжевая, розовая, бирюзовая);
- свои стили `.ws` на Java (см. `docs/styles.md`).

Всё это хранится в `SharedPreferences` и применяется сразу ко всем экранам.
Сброс — кнопка «Сбросить оформление» внизу экрана оформления.

## Сервер (Supabase)

Общий список файлов требует бэкенда. Приложение работает с Supabase напрямую,
без своего сервера и без библиотек — только `HttpURLConnection`.

1. Создай бесплатный проект на [supabase.com](https://supabase.com).
2. Открой **SQL Editor**, вставь скрипт из `app/src/main/res/raw/setup.sql` и нажми **Run**.
   Скрипт создаёт таблицу `public.files`, политики доступа и публичный бакет `wexstore`.
   Его можно выполнять повторно: колонка `icon_path` добавится, если её ещё нет.
3. Открой **Project Settings → API** и скопируй **Project URL** и **anon public key**.
4. В приложении: шестерёнка → вставь URL и ключ → **Сохранить** → **Проверить подключение**.

Anon-ключ публичный по задумке Supabase, доступ ограничивают политики из SQL.
Бесплатный тариф принимает файлы до 50 МБ.

Пока сервер не подключён, приложение показывает встроенные демо-файлы и не даёт
публиковать — кнопка «Опубликовать» предложит открыть настройки.

Можно вшить сервер в сборку: заполнить `DEFAULT_URL` и `DEFAULT_KEY`
в `app/src/main/java/com/wexresprise/store/StoreConfig.java`.

## Стили .ws

Файл `.ws` — это ZIP с `manifest.json` и скомпилированными dex-классами.
Стиль получает `StyleConfig` и может перекрасить, переформатировать и перестроить
весь интерфейс. Подробности и пример — в [docs/styles.md](docs/styles.md).

Стиль — это исполняемый код с правами приложения, поэтому перед импортом
приложение показывает предупреждение. Ставь только те стили, которым доверяешь.

## Если приложение упало

В версии 1.2 появился аварийный экран. При непойманной ошибке приложение
открывает отдельный экран с точным текстом исключения, версией, моделью
телефона и кнопками **Скопировать**, **Отправить**, **Сбросить оформление**
и **Закрыть**. Экран живёт в отдельном процессе, поэтому показывается даже
тогда, когда основной процесс уже завершился.

Если экран не успел появиться, при следующем запуске будет диалог
«Прошлый запуск завершился ошибкой» с теми же кнопками. Копия текста также
лежит в `Android/data/com.wexresprise.store/files/last-crash.txt`.

## Сборка

Через GitHub Actions: workflow `.github/workflows/build.yml` собирает release APK
и кладёт его в артефакт `WexrespriseStore-apk`.

Локально в Android Studio: открыть папку проекта, JDK 17, Android SDK 35.

Подпись release — `keystore/wexresprise.p12` (alias `wexresprise`).
Ключ тот же, что у Wexresprise Launcher, поэтому обновления совместимы.

## Структура

```
app/src/main/java/com/wexresprise/store/
  MainActivity.java        — вкладки, список, публикация, установка APK
  SettingsActivity.java    — подключение Supabase, SQL, проверка
  AppearanceActivity.java  — тема, акцент, фон, карточки, стили .ws
  BaseStoreActivity.java   — общая оболочка экранов: тема, фон, отступы
  StoreTheme.java          — настройки + .ws → палитра
  StoreApi.java            — PostgREST + Storage, загрузка с прогрессом
  StoreAdapter.java        — карточки файлов и иконки приложений
  ApkIconExtractor.java    — иконка из APK через PackageManager
  ApkInstaller.java        — установщик и разрешение «неизвестных источников»
  IconLoader.java          — асинхронная загрузка иконок с кэшем
  LauncherIcons.java       — переключение иконки на рабочем столе
  Prefs.java               — настройки сервера и оформления
  AuroraView.java          — анимированный фон
  GlassDrawable.java       — «жидкое стекло»
  BadgeView.java           — значок типа файла
  DemoData.java            — демо-список
  style/                   — API стилей и установка .ws
docs/styles.md             — формат .ws и пример стиля
demo/                      — файлы для демо-режима (раздаются с GitHub raw)
```
